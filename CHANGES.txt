Major Changes
=============

1. NEW: 15_mesh_3d_tiles/ Subdirectory
   -------------------------------------
   A new standalone project for processing 3D mesh tiles with Cesium 3D Tiles format.

   Key components:
   - Cesium3d_meshtoolbox.h (520 lines): Comprehensive mesh utilities including:
     * Box mesh generation with parametric dimensions
     * Cylinder mesh creation (parametric height/radius)
     * Point cloud mesh utilities (lidar format)
     * AABB computation with scene graph transformation support
     * Scene composition from multiple primitive meshes

   - test_mesh_3d_tiles.cpp (205 lines): GoogleTest test suite with:
     * Test fixture class (workspace creation, data directory management)
     * GLB file loading tests (tb_2, tb_3 datasets)
     * Georeferenced scene generation ("graveyard" test with 1000+ boxes)
     * AABB verification with transformation matrices

   - Test data files:
     * data/tb_2/actual.glb (582 KB)
     * data/tb_3/actual.glb (585 KB)
     * data/georeferenced_graveyard_scene_actual/ (b3dm tiles, tileset.json)

   - Build configuration:
     * Standalone CMakeLists.txt with GoogleTest integration
     * CMakePresets.json (Visual Studio 2022 generator)
     * CMakeUserPresets.json (multiple platform presets: default, cherry, windows-developmentyk, kestrel)
     * vcpkg.json with dependencies: fmt, assimp
     * CLAUDE.md with project-specific build/test instructions

2. ENHANCED: 08_assimp_junk/ - Draco Support
   ------------------------------------------
   Added vcpkg overlay port to enable Draco mesh compression in Assimp builds.

   Changes:
   - vcpkg-overlays/assimp/: Custom port files
     * portfile.cmake (97 lines): Modified vcpkg port with ASSIMP_BUILD_DRACO=ON
     * build_fixes.patch (493 lines): Assimp build system patches
     * vcpkg.json: Port manifest with draco dependency
     * README.md: Documentation for overlay port usage

   - CMakeLists.txt: Added ASSIMP_BUILD_DRACO cache variable

   - test_assimp.cpp: New test cases
     * load_glb_mesh_draco: Tests Draco-compressed GLB mesh loading (1.7M faces, 1M+ vertices)
     * load_glb_mesh_draco_tinygltf: Validates same file with tinygltf library
     * Updated meshtoolbox_tile1: Changed expectations from failure to success (34 meshes)

   - test_data/GM21378_read_draco_b3dm/tile_draco.glb (5.8 MB): Large Draco test asset

   - CMakePresets.json: Updated VCPKG_OVERLAY_PORTS configuration

   - CLAUDE.md: Updated build instructions with overlay port usage

3. CLEANUP: Build Artifacts
   -------------------------
   - Removed vcpkg_installed/ directory from git tracking (build output cleanup)
